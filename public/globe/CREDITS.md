# Earth imagery

Earth surface and cloud textures use NASA Blue Marble imagery.
Credit: NASA Goddard Space Flight Center and the Blue Marble visualisation team.

Original surface map:
https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57730/land_ocean_ice_2048.jpg

Original cloud map:
https://eoimages.gsfc.nasa.gov/images/imagerecords/57000/57747/cloud_combined_2048.jpg

Background and provenance:
https://science.nasa.gov/earth/earth-observatory/the-blue-marble-2181/

NASA media usage guidance:
https://www.nasa.gov/nasa-brand-center/images-and-media/

The maps were compressed to WebP for this site. The cloud map was resized to
1024 by 512 pixels. This historical satellite composite is a decorative Earth
visualisation, not a view of current weather or athlete locations.

The fallback globe image is rendered from these textures using the site's
Three.js scene. No NASA endorsement is implied.
